# What each slot needs (all times US Eastern)

Run times and snapshot rule: the cover shows the snapshot time; use nothing newer than the run start.

## premarket (run ~8:50 AM, publish by ~9:10 AM)
Collect: Nasdaq-100 and Dow futures % with the time; overnight/Asia/Europe moves if big; today's economic releases with actual vs consensus
(BLS jobs/CPI, etc., 8:30 AM releases); Fed-odds or yield moves if notable; 4-6 pre-market movers with reason (earnings, deals) and time;
what to watch at 9:30. Recap yesterday's close in one line for context.
Slides: cover, futures board, data/bignum (the big release), pre-market movers, what to watch, cta.

## midday (run ~12:50 PM, publish by ~1:10 PM)
Collect: index % at the run time vs the morning reading (state both times); the main theme of the session; any chart-worthy series
(e.g. a ratio tracked through the day, only from timestamped readings); 5-6 midday movers with reason; one scheduled data point (sentiment, Fed speakers).
Slides: cover, indexes now vs morning, theme chart, movers, data point, cta.

## close (run ~4:10 PM, publish by ~4:40 PM)
Collect: official closes and % for Nasdaq Composite, S&P 500, Dow, Russell 2000 (two outlets agree); the day's story with numbers; best/worst movers
(from a table, say "selected"); week or month context if it is Friday or month-end; what is next (CPI/FOMC/earnings dates confirmed from BLS, Fed, company IR).
Slides: cover, closing scoreboard, theme data slide, movers, context + what's next, cta.

## Always
- 5 or more claims in the spec's `claims` list: claim, value, source, url, as_of, confidence.
- Footer on every non-cover slide naming its sources.
- Caption: lead with the numbers and times, 120 words or fewer, 6-9 hashtags, standing disclaimer, next update time.
